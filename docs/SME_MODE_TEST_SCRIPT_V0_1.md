# SME 實測主持腳本 — SME-mode 三問翻轉版（V0.1）

> 搭配桌面問卷 `SME-三分鐘測試問卷.pdf` 使用。
> 本版對應 CDD 2026-09-07 SME-mode pivot 三批（結果首屏三問速答、快速入口三層、
> 語音輸入預留位）。問卷 A1–A5 維持不變；主持流程加入「三問速答是否一看就懂」的檢查。

## 對象與方式（沿用問卷）
- 三位未參與開發的 SME 老闆（進出口／製造／貿易相關尤佳），每位單獨進行，全程約 8–10 分鐘。
- 目的：驗證「老闆三分鐘內能否看懂：這筆單卡在哪、下一步要拿什麼、現在該不該投入」。
- 不是測試受測者，是測試網站。主持人只記錄、不提示、不引導。

## 進行方式（主持人用）
1. 讓受測者用自己的手機或電腦，開啟作品集首頁 https://paulstradecraft.com/（繁中）。
2. 請他「想像自己是一家台灣中小企業老闆，收到一封海外詢價」，自己決定下一步點哪裡。
3. 計時 3 分鐘；期間不提示，只記錄他說什麼、停在哪、點到哪、問「這是什麼」。
4. 3 分鐘後請他關閉頁面，再依下方三問回想回答。

## 三個核心問題（先自由回答，再追問）
- **Q1 這筆訂單卡在哪？** 追問：只能講一句話——48 萬美元的單現在為何不能直接接下來？
- **Q2 下一步要拿什麼？** 追問：該跟對方要什麼資料／文件？跟誰要？
- **Q3 現在該不該投入？** 追問：畫面有沒有直接告訴你「先別投入、要補什麼」？（三問速答第三題）

### 本版新增檢查（SME-mode pivot 對應）
- **B1 三問速答**：結果第一屏是否一眼看到「收不收得到錢／做不做得完／該不該投入」三行？
  他能否用自己的話重述三行答案（樣例：尚未鎖定 → 先拿書面付款條件）？
- **B2 快速入口**：點「評估我的商機」（blank 模式）後，首屏是否只有 7 欄左右、看得懂要填什麼？
  追問：哪一欄看不懂？會想直接關掉，還是先填一點試試？
- **B3 語音輸入**：入口上方「🎙 語音輸入（規劃中）」——受測者是否誤以為現在就能講？誤解率記錄。
- **B4 語言**：全程繁中是否自然？有無夾英文造成困惑（Incoterm／KYC／margin 等）？

## 判定標準（主持人用）
- **通過**：受測者能用自己的話說出「付款條件還沒談攏／要書面付款排程／能帶進報價或談判前的會議」
  任一核心，未在關鍵路徑卡死；三問速答至少能讀懂兩行。
- **未通過**：3 分鐘內找不到重點，或把輸出誤會成「自動下單／報價系統」。
  任何誤解都記錄，供下一輪修改。
- **特別留意（B1）**：若受測者能答 Q1/Q2 卻看不到「該不該現在投入」的答案，代表三問速答第三行的
  位置或措辭仍需調整——記錄他找答案的路徑。
